FOLDER FOTO KENDARAAN
=====================

Simpan foto kendaraan asli di folder ini, misalnya:

  assets/cars/innova-reborn-hitam.jpg
  assets/cars/alphard-2022.webp

Lalu di Admin > Unit Kendaraan > Edit > Foto Kendaraan > tab "URL Gambar",
isi dengan path relatif:  assets/cars/innova-reborn-hitam.jpg

Tips:
- Gunakan rasio 16:10 (mis. 1280 x 800 px) agar tampil rapi di kartu katalog.
- Kompres foto (< 300 KB) agar website tetap cepat.
- Memakai file di folder ini TIDAK memakan kuota LocalStorage
  (berbeda dengan fitur Upload yang menyimpan foto sebagai Base64).

Jika foto dikosongkan, website otomatis menampilkan ilustrasi kendaraan
sesuai tipe dan warna unit.
